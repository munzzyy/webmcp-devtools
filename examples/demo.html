webmcp-devtools demo page

This page defines document.modelContext itself, with a tiny inline shim, so you can try the WebMCP DevTools panel without a flagged Chrome build or the real @mcp-b/webmcp-polyfill package. If Chrome's own WebMCP is turned on, it registers the same tools through that instead. Open DevTools and look for the WebMCP tab.
